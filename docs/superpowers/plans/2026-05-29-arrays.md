# Arrays Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 1-dimensional arrays (literals, index read, index write, `length` builtin) across the full compiler pipeline.

**Architecture:** Recursive-descent compiler with 7 stages (Lexer → Parser → Semantic → TypeChecker → Optimizer → Interpreter). Each stage dispatches on AST node type via `GetType()`. Arrays add 2 tokens, 3 AST node types, 3 array `SimpleType` enum values, and parallel dispatch branches in every stage. Runtime array value = `List<object>` (mutable reference semantics).

**Tech Stack:** C# / .NET 10. No unit-test framework in this repo — each stage is an executable. The verification harness is `Functions/Program.cs`, a full-pipeline runner invoked with `dotnet run --project Functions`. The plan uses one evolving integration sample: each task moves the pipeline's failure point forward until the sample runs correctly.

**Spec:** `docs/superpowers/specs/2026-05-29-arrays-design.md`

---

## Target Language Surface

```
var a = [1, 2, 3];      // array literal
print a;                // [1, 2, 3]
print a[0];             // 1
a[1] = 42;             // index write
print length(a);        // 3
```

```csharp
    private Expression ParsePrimary()
    {
        Expression expr = ParsePrimaryBase();
        while (Match(TokenType.LBRACKET))
        {
            Expression index = ParseExpression();
            Consume(TokenType.RBRACKET, "Expected ']' after index");
            expr = new ArrayIndexExpression(expr, index);
        }
        return expr;
    }
    private Expression ParsePrimaryBase()
    {
        if (Match(TokenType.NUMBER))
            return new NumberExpression(double.Parse(Previous().Value, System.Globalization.CultureInfo.InvariantCulture));
        if (Match(TokenType.LBRACKET))
        {
            List<Expression> elements = new List<Expression>();
            if (!Check(TokenType.RBRACKET))
            {
                elements.Add(ParseExpression());
                while (Match(TokenType.COMMA))
                    elements.Add(ParseExpression());
            }
            Consume(TokenType.RBRACKET, "Expected ']' after array elements");
            return new ArrayLiteralExpression(elements);
        }
        if (Match(TokenType.ID))
        {
            string name = Previous().Value;
            if (Match(TokenType.LPAREN))
            {
                List<Expression> args = new List<Expression>();
                if (!Check(TokenType.RPAREN))
                {
                    args.Add(ParseExpression());
                    while (Match(TokenType.COMMA))
                        args.Add(ParseExpression());
                }
                Consume(TokenType.RPAREN, "Expected ')' after arguments");
                return new CallExpression(name, args);
            }
            return new VariableExpression(name);
        }
        if (Match(TokenType.LPAREN))
        {
            Expression inner = ParseExpression();
            Consume(TokenType.RPAREN, "Expected ')' after expression");
            return new GroupExpression(inner);
        }
        throw new Exception("[Parser Error] Unexpected token '" + Peek().Value + "' at Line " + Peek().Line + ", Column " + Peek().Column);
    }
```

```csharp
        if (elemType == SimpleType.Number) return SimpleType.NumberArray;
        if (elemType == SimpleType.Bool) return SimpleType.BoolArray;
```

## Notes for the implementer

- **Dispatch order matters.** In Semantic, TypeChecker, and Interpreter the `length` builtin must be checked *before* the user-function lookup so `length` works without a declaration, yet a user-defined `length` still shadows it (guarded by `!IsFunctionDeclared("length")` / `!_functions.ContainsKey("length")`).
- **`ParsePrimary` postfix loop** is what enables `a[i]` after any primary and chained `a[i][j]`. The literal-vs-index distinction is handled by `ParsePrimaryBase` (literal) vs the loop (index).
- **Index assignment** is detected after parsing the LHS expression: if it is an `ArrayIndexExpression` followed by `=`, it becomes `IndexAssignStatement`; this is why `ParseAssignOrExpressionStatement` parses the expression first instead of only looking ahead for `ID =`.
- **Runtime array = `List<object>`**, shared by reference, so `a[i] = x` mutates the same list the variable holds. No copy.
- **Index cast** truncates `double`→`int` via `(int)d`.
